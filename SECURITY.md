# Security Policy

## Supported Versions

Only the latest version of WebScope is currently supported with security updates.

| Version | Supported          |
| ------- | ------------------ |
| 0.2.x   | :white_check_mark: |
| < 0.2.0 | :x:                |

## Reporting a Vulnerability

We take the security of WebScope seriously. If you believe you have found a security vulnerability, please report it to us responsibly.

**Please do not report security vulnerabilities via public GitHub issues.**

Instead, please send an email to urgorrigaston@gmail.com.

We will acknowledge receipt of your report within 48 hours and provide a timeline for addressing the issue.

### SSRF Protection

This project includes a built-in SSRF protection policy to prevent the crawler from accessing private or internal network addresses. If you find a way to bypass this protection, please report it as a high-priority security issue.
